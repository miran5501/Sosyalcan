# SosyalCan — Web + API

Next.js uygulaması: web arayüzü ve mobil uygulamanın da kullandığı API. Kurulum, komutlar ve testler için kökteki [README](../../README.md).

Sık kullanılanlar (bu klasörde):

```sh
npm run dev        # geliştirme sunucusu (http://localhost:3000)
npm test           # birim testleri
npm run test:db    # veritabanı testleri
npm run test:e2e   # tarayıcı testleri
npm run build      # üretim derlemesi (önce ortam değişkenlerini denetler)
```
